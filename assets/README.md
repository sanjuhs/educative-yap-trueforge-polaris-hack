# Bundled visual assets

`cafe.png` is an AI-generated photographic asset created with OpenAI image generation on 2026-09-26 for this project. It depicts a fictional café's coffee and pastry. It is included under this repository's MIT terms. It is not a photograph of a real business.

The animated HTML/CSS demonstration reuses this image locally. Re-rendering it does not call an image model. Its original generation happened through the development assistant, outside this app's API metering; that one-time cost is excluded from per-video estimates.
